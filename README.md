# Navkis Auditorium Booking

## Run in Visual Studio Code

Open this folder in VS Code and run **one** of these commands in the terminal:

### Windows
```bash
py -m pip install -r requirements.txt
py app.py
```

If your `py` launcher is not available:

```bash
python -m pip install -r requirements.txt
python app.py
```

Then open:

http://127.0.0.1:5000
